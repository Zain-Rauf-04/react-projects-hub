📒 ContactVault – Contact Management App
ContactVault is a modern, responsive contact management application built with React.js. It provides a simple and intuitive interface to manage personal contacts efficiently.

✨ Features
➕ Add Contacts – Add new contacts with name, email, phone number, and category.
✏️ Edit Contacts – Update existing contact information easily.
🗑️ Delete Contacts – Remove contacts you no longer need.
🔍 Search Contacts – Quickly find contacts by name or other supported search fields.
🏷️ Category Filtering – Filter and organize contacts based on categories.
📱 Responsive Design – Works across desktop, tablet, and mobile screens.
🎨 Clean User Interface – Simple and user-friendly design.


🛠️ Technologies Used
- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- Vite
- Lucide React (for icons, if used)

🚀 Getting Started
Follow these instructions to run the project locally.

1. Clone the Repository
git clone https://github.com/Zain-Rauf-04/react-projects-hub.git

3. Navigate to the Project Directory
cd react-projects-hub/contact-vault

4. Install Dependencies
npm install

5. Start the Development Server
npm run dev

6. Open in Browser
Open the local URL provided by Vite in your terminal, usually:
http://localhost:5173
